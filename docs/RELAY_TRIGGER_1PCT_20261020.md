# 반대 종목 연쇄 매수 발동선 -1% 변경

2026-10-20 사용자 지시로 `config.RELAY_OPPOSITE_TRIGGER_PCT`를 `0.015`에서 `0.01`로 변경했다. 보유 종목의 자기 매수가 대비 신선한 WebSocket Bid가 -1.0% 이하일 때 빈 반대 종목으로 연쇄 매수를 시도한다. 세션·예산·원장·미체결 검사와 중복 차단은 유지한다.

- 고점 대비 추적 하락 폭: **-0.3% 유지** (`TRAILING_DROP_PCT=0.003`).
- 최초 포지션 트레일링 발동: +1.5% 유지.
- 연쇄 포지션 트레일링 발동: +1.0% 유지.
- 초기 손절: -2% 유지. 배분·최초 GBDT 진입·사이클 종료 조건 유지.

매매 기준은 config 한 곳을 변경하면 된다. 다만 현재 운영은 소스/config SHA를 검증하므로, 새 config SHA를 활성 실행 전략 manifest에 반영하고 쉐도우의 별도 설정 승인 정보도 함께 갱신했다. 쉐도우 학습 정책과 모델 파일은 변경하지 않았다. 핵심 실행 코드도 변경하지 않았다.

격리 QA에서 필수 무결성 9개와 관련 회귀 214개, 합계 **223개 통과**. 최초 SOXL/SOXS 양쪽의 -1% 경계, 직전 미발동, 역할별 트레일링 및 기존 연쇄/청산 경로를 검사했다. 새 manifest를 사용한 factory의 소스 검증과 쉐도우 설정 승인 로딩도 통과했다. 네트워크/격리 밖 쓰기 guard 위반 0건.

운영 Runner는 실행 중이지 않았으며 이번에도 시작하지 않았다. 다음 Runner 실행부터 적용한다. 운영 READY 원장 상태, 모델, 기존 매매 로그는 변경하지 않았고 실주문은 전송하지 않았다.
