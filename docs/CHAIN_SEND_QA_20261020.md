# 연쇄 매수 전송 검증 (2026-10-20)

연쇄 BUY도 최초 BUY와 같은 최신 WS Ask + config 버퍼 전송 경로를 사용한다. 원장 사전 확인, 유량·인증 처리, TLS 연결 준비 후 가격을 다시 계산한다. 이번에는 최종 가격 계산 시 연쇄 예약 ID와 현재 주문 의도 ID가 일치하는지, 최초 포지션의 수량·평균 매수가가 직전 증권사 원장 검증값과 같은지도 재확인하도록 보강했다.

최초 포지션 -1% 조건이 해제되거나 호가가 오래됐거나, 가격 상승으로 기존 사이클의 49% 한도를 넘으면 전송하지 않는다. 이때도 예약을 소비한 사이클은 별도 연쇄 매수를 반복하지 않는다. 동일 주문 의도의 미체결 취소 후 잔여 수량 재발주는 기존 정책을 따른다. 최초 1회 + 연쇄 1회 이후 전체 청산까지 신규 진입을 막는 규칙은 유지한다.

최초/연쇄 49%·49%, 손절 -2%, 최초 추적 +1.5%/-0.3%, 연쇄 추적 +1%/-0.3%, 시간 제한 및 장 마감 청산은 변경하지 않았다. config·모델·계좌 READY 파일도 변경하지 않았다.

격리 복제에서 핵심 무결성 9개와 관련 회귀 282개, 총 291개가 통과했다. 신규 10개는 양방향 연쇄 전송가 갱신, 반등·오래된 호가·예산 초과 차단, 예약/최초 수량 변경, 연결 준비 중 반등, 부분 체결 후 잔여 수량만 재발주, 접수 불명 상태의 재시작 보존과 중복 차단을 검증한다. 부분 체결 시험은 합성 원장 증거를 사용했다. 네트워크 및 외부 쓰기 가드 차단 횟수는 0이다.

실계좌 API·실주문·텔레그램 전송·Runner 재시작은 수행하지 않았다. 다음 정상 Live runner 시작부터 변경 코드가 적용된다. 실제 시장의 지정가 체결을 보장하는 검증은 아니다. 증거는 `research/chain_send_qa_20261020/result.json`과 해당 폴더의 테스트 로그·변경 diff에 저장했다.
