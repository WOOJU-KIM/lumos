# 실전·전체 운영 쉐도우 초기 손절 2% 고정

2026-10-20 사용자 지시에 따라 초기 손절을 매입가 대비 **−2.0% 고정**으로 변경했다. 종전 ATR 기반 2.0~3.2% 확대를 적용하지 않는다. 수수료 차감 전 가격 기준이며 실제 청산 체결 수익률은 호가·슬리피지·비용에 따라 −2%보다 낮을 수 있다.

## 적용 범위

- `config.py`: `SL_MIN_PCT = SL_MAX_PCT = 0.02`. ATR 피처와 모델은 유지한다.
- 실전 `core/live_runner.py`: 신규 매수, 체결 확인 및 부분체결 보존, 원장 복구, WebSocket 청산, 주기적 원장 보유 청산 모두 config의 2%를 사용한다. 기존 포지션 메타데이터에 남은 더 넓은 `sl_pct`도 실제 청산 판단을 넓히지 않는다.
- 기존 15분 강제진입 `core/shadow_tracker.py`: ATR 인자와 무관하게 2%로 초기 손절가를 설정한다. 인자·슬롯 스키마·중복 진입 방지는 유지한다.
- 추가 5개 쉐도우의 primary/forced 계정: `runtime.Ledger`에서 모두 초기 2% 적용. SOXL/SOXS에 동일하게 적용한다.
- +1.5% 트레일링 발동, 고점 대비 0.3% 추적 청산, 최대 TP, 90분 시간 청산, EOD 및 진입 인터락·98% 비중은 유지한다. 과거 연구 전략 비교용 R&D 시뮬레이터는 운영 쉐도우 계정이 아니다.

## 쉐도우 고정 정책과 실행 정책

5개 모델의 `policy.json`, 아티팩트 및 학습 당시 라벨은 변경하지 않았다. 별도 `execution_policy.json`이 사용자 승인 변경인 `SL_MAX_PCT`만 허용한다. 현재 config 파일 SHA, 원래 정책 SHA, 원래 config SHA 및 해당 대입값을 원복한 AST SHA를 함께 검증한다. 다른 config 수정은 계속 차단한다.

`common.CONFIG`는 학습 provenance의 과거 설정이고, `load_execution_config()`가 현재 실행 정책을 반환한다. 실행 로그의 `EXECUTION_EXIT_POLICY`에 `stop_mode=FIXED`, `initial_stop_pct=0.02` 및 실행 정책 SHA를 남긴다. 이전 거래 결과를 새 규칙으로 소급 수정하지 않았다. 현재 모델의 과거 학습 라벨과 새 실행 손절 조건이 다르다는 점을 구분해야 한다.

## 검증 및 적용 시점

네트워크·외부 쓰기·자식 프로세스를 차단한 최신 소스 복제 환경에서 다음을 확인했다.

- `python -B tests/test_system_integrity.py`: 9개 통과.
- 관련 회귀: 107개 통과. 실전 WebSocket/원장 주기 검사에서 예전 3.2% 메타데이터가 있어도 −1.99% 보유, −2.01% 손절. 기존 트래커는 높은 ATR에서도 양방향 2% 경계 확인. 5개 쉐도우 × primary/forced × 양방향에서도 같은 경계와 다음 Bid 청산 확인. 트레일링/TP/TIME/EOD 회귀 통과.
- 실제 쉐도우 실행 파일에서 5개 모델을 로딩하고 승인 설정으로 시작 후 `RUN_STOP valid=true` 종료. 시장 입력 0건인 격리 시작 검사이며 실시간 장중 매매 결과를 의미하지 않는다. API 호출·네트워크 시도·격리 외부 쓰기 0건.
- 활성 실전 모델·매니페스트와 쉐도우 고정 정책·모델 매니페스트 SHA 보존 확인.

운영 Live Runner나 실계좌를 시작하지 않았다. 다음 정상 Live Runner 시작부터 적용되며 기존 `FOLLOW_LIVE_RUNNER` 쉐도우 동반 시작·종료 설정을 유지한다.

검증 로그·변경 SHA·작업 전후 diff: `research/fixed_stop_20261020/`. 테스트 구성 중 누락된 모의 Runner 속성은 보완 후 전체 재실행했고, 잘못된 작업 디렉터리에서의 별도 테스트는 외부 쓰기 차단으로 실패하여 격리 복제 경로에서 재실행했다. 최종 결과는 위 통과 수치다.
