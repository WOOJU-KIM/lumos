# 절대값 8개 피처를 사용하는 실전 모델 전환

사용자 지시: 절대값 피처로 실전 모델을 바꾸고 49%/49% 매매는 유지한다.

후속 사용자 결정: 이 절대값 피처 구성을 실전에서 계속 유지한다. 98%와 49%/49%는 연구 백테스트에서 비교하며, 실전은 49%/49%를 유지한다. 비교 결과는 `research/absolute_allocation_wfa_20261021/report.md`에 보존한다.

## 모델 구성과 학습

- 스키마 `v4_champion`, 실전 식별자 `Absolute_72`. 오래된 모델 파일을 재사용하는 것이 아니라, 이전 72개 피처 순서로 새로 학습했다.
- ATR 1개, 볼린저·켈트너 상하단 4개, MACD·시그널·히스토그램 3개만 가격 단위 절대값을 사용한다. 나머지 64개 정의는 보존한다.
- 모델 SHA256: `e3e4499a9bf4731dff1d94ff9bffedc45eb9f708f35abf60aa1955b1053fb1ae`.
- 학습 원시 봉: 2020-07-27~2026-10-20, 44,352개. 준비 구간 38개와 미확정 라벨 6개를 제외한 44,308개를 사용했다. 10년 상한 내 실제 보유 약 6년이다.
- 절대값 스키마가 완전한 기존 실전 기록 32개를 기존 2.5배 정책으로 사용했다. 기존 상대값 모델의 완전 표본 22개와 개수가 다르다. 기록의 라벨·체결 가격 품질 한계는 기존대로 명시하며 증권사 순수익 검증 표본이라고 주장하지 않는다.
- 반복 학습의 트리 문자열 동일, 최근 120개 입력의 유한 확률·합계 1·클래스 `[0,1,2]`를 확인했다.
- 절대값 모델은 별도 gain 감쇠 없이 1/1을 사용한다. `config.py`는 변경하지 않았다. 기존 0.5/0.5 설정은 `B_normalized` 재학습에만 적용되므로 새 절대값 모델에는 적용되지 않는다.

## 운영과 보존

- 최초 49%, 연쇄 49%, 연쇄 −1%, 최초/연쇄 추적 발동 +1.5%/+1%, 추적 −0.3%, 공통 손절 −2%, 90분, EOD와 사이클 제한을 보존한다.
- 이전 상대값 0.5/0.5 아티팩트와 기존 Champion 폴백을 그대로 보존한다. 활성 매니페스트만 새 불변 버전을 가리킨다.
- 주간 자동 재학습 기본값은 활성 매니페스트의 스키마를 따른다. 절대값 학습의 피처 순서도 명시적으로 고정한다. 실험 스키마 차단과 원자적 교체·오래된 작업 차단을 유지한다.
- 절대값 스키마를 의도적으로 주 모델로 선택한 경우 자동 폴백으로 표시하지 않는다. 실제 폴백과 명시적 롤백은 계속 구별한다. 자동 재학습 알림은 실제 모델 ID와 스키마를 표시한다.
- 실전 모델과 동일 모델을 쓰도록 설계된 방향 비교 쉐도우 2개만 새 모델에 연결한다. 기존 5개 모델과 이전 B72 보존 쉐도우는 바꾸지 않는다.
- 쉐도우 입력의 기존 32×72 시퀀스와 고정 full_features는 보존한다. 추가 절대값은 별도 `relay_features`로 전달하며 허용 키·유한 값·입력 해시·감사 저장을 검증한다.
- 새 분할·병합 감지와 당일 신규 거래 차단 자동화는 이 변경에 포함하지 않는다.

## 검증과 실행 범위

네트워크·자격증명·실주문을 차단한 격리 복제에서 실전 로더, 원자적 재학습, 배포 해시, 실제 Runner 생성 경로와 모의 거래를 검증한다. 원본 `scripts/live_trade_test_clean.py`와 `core/mock_kiwoom_feeder.py`는 수정하지 않는다.

최근 5일 재생은 합성 틱 콜백 2,730건, 모델 판단 6건, 승인 1건이다. 기존 비동기 재생 루프 때문에 모든 15분봉 판단을 빠짐없이 재생한 검증이라고 주장하지 않는다. 통제된 실제 연쇄 매매 메서드의 6개 시나리오는 최초 추적, 양방향 연쇄·손절·추적, EOD 양쪽 청산, 추가 연쇄 차단, 모두 청산 후 새 봉 재진입을 검증한다. 모의 브로커 체결이며 거래소 체결 품질 검증은 아니다.
