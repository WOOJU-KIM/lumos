# 현재 연쇄 전략에 맞춘 텔레그램 알림

2026-10-20 사용자 지시로 알림을 최신화했다. 매매 조건과 config, 활성 추론 모델, 쉐도우 실행 코드는 변경하지 않았다. 다음 정상 Live Runner 시작부터 적용된다. 이번 작업에서 실제 Runner를 실행하거나 텔레그램 메시지를 보내지는 않았다.

- 시작·개장 알림: 최초/연쇄 각 49%, -1% 반대 진입 1회, 최초 +1.5%·연쇄 +1% 추적 발동, 고점 -0.3%, 고정 손절 -2%, 최대 익절·시간 종료·두 종목 EOD 청산을 현재 config에서 표시한다. ATR 가변 손절 표현을 제거하고 뉴욕시간으로 안내한다.
- 15분 브리핑: GBDT는 최초 진입용이고, 진행 중인 사이클에 새 GBDT 매수를 추가하지 않으며, 모두 청산·주문 정리 후 다음 새 15분봉에서 재개함을 안내한다.
- 최초 매수 체결: 최초 구분, 실제 수량·금액, 49% 배정 한도, GBDT 점수·모델, 최초 포지션의 추적 조건을 표시한다.
- 연쇄 매수 체결: 연쇄 구분, 실제 수량·금액, 49% 한도, 원래 종목의 자기 매수가 대비 -1%라는 WebSocket Bid 조건을 표시한다. 연쇄 진입에 GBDT 신규 판단을 사용했다는 표현이나 0% 확신도·불명확한 모델 표시는 하지 않는다.
- 개별 청산: 최초/연쇄 구분과 다른 전략 포지션을 표시한다. 한쪽만 청산해도 전부 현금화된 것으로 안내하지 않는다. 표시 손익은 알림 기준 가격의 비용 전 추정치임을 명시한다.
- 사이클 종료: 원장·로컬 포지션·대기/미해결 주문이 정리되고 기존 사이클 상태가 종료된 뒤, 브로커 미체결 조회도 비어 있음을 확인한 경우에만 별도 알림을 만든다. 모두 정리되기 전에는 전송하지 않는다. 체결·비용 대사 전 합산 손익을 임의로 만들지 않는다.
- 연쇄 Runner에 한해 기존 두 번째 중복 매도 알림을 억제했다. 이 알림의 기존 ‘100% 현금화 완료·새 진입 대기’ 문구가 한쪽 청산 때 잘못 전송되는 것을 막는다. 기존 단일 포지션 Runner의 알림은 유지한다.

최초/연쇄 메타데이터는 기존 매수 알림의 `model_snapshot_info`로 전달한다. 기존 모델 판단 dict는 복사하므로 변경하지 않는다. 개별 청산의 남은 종목은 매도 범위의 복사본에만 붙인다. 알림 실패가 매수·청산·사이클 원장 처리를 되돌리거나 주문 락을 유지시키지 않도록 예외를 격리했다. 실제 전송은 기존 큐/전송기를 사용하며 전달 성공을 보장하는 기능은 추가하지 않았다. 실패 알림을 재시작 후 자동 재전송하는 기능도 이번 범위에 포함하지 않는다.

격리 복제에서 `python tests/test_system_integrity.py` 9개와 관련 회귀 251개, 총 260개 통과했다. 신규 알림 검증 11개에는 실제 매수·매도 helper와 메시지 템플릿 연결, 한쪽 청산, 두 종목 EOD, 원장 미해결 시 종료 알림 차단, 알림 오류 시 매매 보존, HTML 이스케이프, 구 알림 호환성을 포함한다. 가짜 체결에서 최초·연쇄·개별 매도 2개·사이클 종료의 5개 메시지를 캡처했고 중복 구 알림 0개를 확인했다. 네트워크·외부 쓰기 차단 시도는 최종 검증에서 0건이다.
