# 실전 유지 · 쉐도우 3개로 개편

> 후속 사용자 지시로 기존 15분 강제 진입 트래커를 현재 실전 절대값 모델로 다시 활성화했다. 비교 쉐도우 3개는 그대로이며 총 관측 전략은 4개다. 아래 비활성화 설명은 최초 개편 시점의 기록이다. [최신 변경](SHADOW_FORCED_RESTORE_20261021.md).

사용자 지시로 기존 실시간 쉐도우 실행 대상을 전부 제외하고, 실전과 동일한 절대값 72개 모델을 사용하는 다음 세 전략만 선택한다. 과거 로그·모델 파일·연구 결과는 삭제하지 않는다.

| 쉐도우 ID | 최초 진입 | 반대 진입 | 매도 |
|---|---|---|---|
| `ABS72_SINGLE_98` | 사이클 자금 98% | 없음 | 손절 −2%, +1.5%부터 −0.3% 추적 |
| `ABS72_RELAY_M15` | 49% | 최초 매수가 대비 −1.5%에서 반대 종목 49% 1회 | 공통 손절 −2%, 최초 +1.5% / 연쇄 +1%부터 −0.3% 추적 |
| `ABS72_STOP_REVERSE` | 49% | 최초 SL 매도 체결 확인 후 반대 종목 49% 1회 | 공통 손절 −2%, 최초 +1.5% / 반대 +1%부터 −0.3% 추적 |

세 전략 모두 같은 완료 15분봉·GBDT 임계값·중립 차단·필터 설정을 사용한다. 90분·최대 익절·EOD와 신규 진입 마감은 기존 config를 따른다. 한 사이클 최초 1회와 반대 1회까지만 허용하며 모두 청산·주문 정리 후 새 15분봉에서 재진입한다. 반대 진입 비중은 최초 사이클 시작 예산의 49%다.

실전은 기존 `Absolute_72` 모델, 최초 49%/연쇄 49%, 최초 −1%에서 연쇄, 고정 손절 −2%와 기존 청산 조건을 유지한다. `config.py`, 실전 모델 파일·매니페스트, 실전 연쇄·주문·원장 정책 소스는 변경하지 않는다.

## 실행 구성

- 선택 기준 파일: `research/shadow_five_full15m_20261018/comparison_shadows.json`. 역사적 디렉터리 이름은 호환성을 위해 유지한다.
- `live_feed.py`는 새 `build_comparison_shadows()`만 호출한다. 이전 5개×primary/forced, 이전 B72 보존 쉐도우, 방향만 비교하던 2개는 실행 대상에서 제외한다.
- 실전 Runner에 붙어 있던 15분 강제 진입 `ShadowTracker`도 비활성화한다. 새 DB 초기화·작업 스레드·가상 진입은 발생하지 않는다. 명시적 독립 DB로 실행하는 과거 트래커 테스트와 기록 열람은 보존한다.
- 새 후보 3개는 하나의 모델 뷰를 공유한다. 모델 SHA·72개 피처 순서·클래스 `[0,1,2]`를 검증하며, 같은 판단 이벤트에는 같은 모델 버전을 사용한다. 다음 주 재학습으로 활성 매니페스트가 바뀌면 새 판단부터 따라간다. 진행 중 포지션은 진입 당시 모델 버전을 보존한다.
- 주간 재학습의 application object 형식도 읽을 수 있도록 joblib 배열 형식을 지원하되, `core.*` 객체는 실행 기능 없는 상태 객체로 읽는다. 관측 프로세스에서 실전 모듈을 가져오거나 브로커를 생성하지 않는다.
- 기존 WebSocket 전용 전달·MARK/POLL/CLOCK·관측 호가 freshness·Runner 소유권 및 동시 종료 규칙을 보존한다. REST 프레임은 매매 입력으로 사용하지 않는다.

## 손절 후 반대 진입 순서

SL 감지는 매도 의도일 뿐이다. 새 전략은 그 시점에 반대 BUY를 만들지 않는다. 이후 실제로 관측된 다음 source Bid에서 가상 매도 체결을 기록하고, 그 체결 ID를 근거로 반대 BUY를 예약한다. 이후 새로 관측된 반대 Ask에서만 가상 매수한다. 매도 미체결·매수 대기 중에는 신규 GBDT 진입이 차단된다.

최초 익절·트레일링·TIME·EOD에는 반대 진입하지 않는다. 반대 포지션이 손절돼도 세 번째 매수는 없다. 진입 마감 이후에는 SL 체결이 나더라도 반대 매수를 차단한다. 신선한 호가가 오지 않으면 체결을 꾸며내지 않으며, 매수 대기는 기존 타임아웃 규칙으로 취소한다.

체결은 다음 관측 호가 기반 가정이며 실제 거래소 대기열·시장충격을 재현하지 않는다. 독립 자금 원장과 종목별 최소 0.20% 비용 차감을 유지한다. 새 전략은 새 로그에서 시작하며 과거 서로 다른 전략의 성과를 이어 붙이지 않는다.

## 검증 및 상태

검증 증빙은 `research/shadow_three_revision_20261021/`에 보존한다. 새 전략 경계·가상 매도 후 반대 매수·양방향·수량·추적·EOD·타임아웃·모델 교체·파일 저장 및 재읽기, 기존 주문·연쇄·원장·쉐도우·수명 연결 회귀와 시스템 무결성을 격리 복제에서 확인한다.

실전 Runner 생성 경로에서 모델 SHA, 실전 49/49·−1%, 배포 소스 해시, 구 강제 트래커의 스레드 미기동과 새 3개 원장을 확인한다. 실제 봉에서 계산한 피처의 모델 확률도 실전 분류기와 일치해야 한다. 운영 러너·실주문은 시작하지 않는다. 다음 정상 Live Runner 시작부터 3개만 함께 시작·종료한다.

최종 결과: 선택 반영 완료(`CONFIGURED`), 새 전략 포함 회귀 230개·시스템 무결성 9개 통과. 실제 피처의 실전/쉐도우 확률 일치, 새 3개 원장, 구 강제 트래커 작업 스레드 미기동, 배포 해시 및 실전 모델·config·연쇄/주문 정책 보존을 확인했다. 운영 프로세스는 기동하지 않았다.
